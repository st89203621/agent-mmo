All five FBXs contain skinned models and authored idle, movement, attack and death animation clips. Imported as Legacy animation for the existing built-in-renderer prototype. The source models are stylized, not photorealistic.

Run the editor menu `Lunhui/Build Boss Art` or batch method `Lunhui.Prototype.BossArtSetup.BuildAssets` to regenerate the five runtime prefabs and palette materials.
