# Ordinary monster art sources

The two imported FBX files come from Quaternius' **Bestiary - Dungeon Monsters Kit** standard/free download.

- `Imp.fbx`, `Puglin.fbx`
- Source: https://quaternius.com/packs/bestiarydungeonmonsterskit.html
- License: Quaternius Asset License (QAL) v1.0, included in `License-Quaternius-QAL.txt`
- Downloaded: 2026-09-06

The runtime also uses the existing `Fox.fbx` and `Wolf.fbx` from `Art/PetSources` as two ordinary-monster variants. Those files are CC0 1.0 and retain their original license file.

`MonsterArtSetup` converts the FBX files to `Resources/Art/Monsters/Monster0.prefab` and `Monster1.prefab`. The generated game package embeds the models in the completed product; the source FBX files are not redistributed as a standalone asset pack.
